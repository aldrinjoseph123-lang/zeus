# Reporting a security problem

Zeus holds a company's customers, prices and margins, so a weakness in it matters.

If you find one, please report it privately through GitHub: **Security → Report a
vulnerability** on this repository. That reaches the maintainer alone. Please do not open
a public issue for it.

Say what you found, where, and how to reproduce it. You will get a reply within a week,
and a fix in a tagged release with a line in the changelog once it is out.

Only the latest tagged release is supported.
